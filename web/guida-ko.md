# MDFlash 빠른 안내

MDFlash는 **입력하는 즉시** Markdown을 서식 있는 텍스트로 바꿉니다. 별도의 미리 보기 없이 글이 바로 모양을 갖춥니다. 이 안내서도 평범한 문서이므로 마음껏 고치며 연습해 보세요.

## 기본

| 입력 | 결과 |
| --- | --- |
| `# 제목` (# 1~6개) | 해당 수준의 제목 |
| `**굵게**` | **굵게** |
| `*기울임*` | *기울임* |
| `~~취소선~~` | ~~취소선~~ |
| `==형광펜==` | ==형광펜== |
| `` `코드` `` | `코드` |
| `[텍스트](https://example.kr)` | 링크 |
| `> 인용` | 인용 |
| `---` | 가로줄 |

빈 줄 맨 앞에서 **/**를 누르면 삽입 메뉴가 열립니다: 제목, 목록, 표, 수식, 다이어그램, 이미지, 각주.

텍스트를 선택하면 서식 도구 모음이 나타납니다.

## 목록

- 줄 앞에 `-`와 공백을 쓰면 글머리 기호 목록
- `1.`과 공백을 쓰면 번호 매기기 목록
  - Tab으로 들여쓰기, Shift+Tab으로 내어쓰기

- [x] `- [ ]`로 할 일 목록 만들기
- [ ] 상자를 클릭하면 체크됩니다

## 표

`|이름|역할|`을 입력하고 Enter를 누르거나 **Ctrl+T**를 사용하세요. 표 위에 마우스를 올리면 행과 열을 추가, 이동, 정렬하는 버튼이 나타납니다.

| 도구 | 용도 |
| :-- | :-- |
| Ctrl+T | 표 삽입 |
| Tab | 다음 셀로 이동 |

## 수식

인라인 수식: $E = mc^2$. 따로 한 줄에 쓰려면 `$$`와 Enter:

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

## 다이어그램

언어를 `mermaid`로 지정한 코드 블록은 다이어그램이 됩니다:

```mermaid
graph LR
  A[쓰기] --> B[저장]
  B --> C[PDF 또는 Word로 내보내기]
```

## 코드

```js
// 100개 이상의 언어 구문 강조
function greet(name) {
  return `안녕하세요, ${name}님!`;
}
```

## 이미지

이미지를 붙여넣거나(Ctrl+V) 창에 끌어 놓으면 문서 옆의 `assets` 폴더에 복사되고 상대 경로로 삽입되어 문서를 그대로 옮길 수 있습니다. 폴더는 환경 설정에서 바꿀 수 있습니다.

## 각주

Markdown은 각주[^1]를 지원합니다: [단락] > [각주]를 사용하세요.

[^1]: 바로 이런 각주입니다.

## 유용한 바로 가기 키

| 작업 | 키 |
| --- | --- |
| 문서 빠른 열기 | Ctrl+P |
| 명령 팔레트 | Ctrl+Shift+A |
| 소스 모드 (원본 Markdown) | Ctrl+U |
| 집중 모드 | F8 |
| 타자기 모드 | F9 |
| 찾기 / 바꾸기 | Ctrl+F / Ctrl+H |
| 폴더 전체 검색 | Ctrl+Shift+F |
| 사이드바 | Ctrl+Shift+L |
| 글쓰기 도우미 (Ollama) | Ctrl+J |
| 제목 1~6, 단락 | Ctrl+1 … Ctrl+6, Ctrl+0 |
| 글머리 기호, 번호, 할 일 목록 | Ctrl+Shift+8, 7, 9 |

전체 목록은 **[도움말] > [바로 가기 키]**에 있습니다.

## Typora를 넘어서

- **탭**: 한 창에서 여러 문서 (Ctrl+Tab으로 전환).
- **버전 기록**: 저장할 때마다 사본을 보관합니다. [파일] > [버전 기록]에서 차이를 보고 되돌릴 수 있습니다.
- **자동 복구**: PC가 갑자기 꺼져도 다시 시작하면 저장하지 않은 텍스트가 돌아옵니다.
- **폴더 검색**: 폴더의 모든 문서에서 단어를 찾습니다.
- **[[위키 링크]]**: Obsidian 보관함과 호환되며 Ctrl+클릭으로 노트를 엽니다.
- **로컬 도우미**: [Ollama](https://ollama.com)가 설치되어 있으면 텍스트를 인터넷으로 보내지 않고 교정, 번역, 요약, 다시 쓰기를 할 수 있습니다.
- **Word로 내보내기**: 추가 프로그램 없이도 가능합니다.
- **9개 언어**: [보기] > [언어].
