# MDFlash 快速指南

MDFlash 会**在你输入的同时**把 Markdown 变成带格式的文本:没有单独的预览,文字立刻成形。本指南也是一个普通文档,你可以随意修改、在上面练习。

## 基础

| 输入 | 得到 |
| --- | --- |
| `# 标题` (1 到 6 个 #) | 对应级别的标题 |
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `~~删除线~~` | ~~删除线~~ |
| `==高亮==` | ==高亮== |
| `` `代码` `` | `代码` |
| `[文本](https://example.cn)` | 链接 |
| `> 引用` | 引用 |
| `---` | 水平线 |

在空行开头按 **/** 打开插入菜单:标题、列表、表格、公式、图表、图片和脚注。

选中文本即可显示格式工具栏。

## 列表

- 行首输入 `-` 和空格,得到项目符号列表
- 输入 `1.` 和空格,得到编号列表
  - Tab 增加缩进,Shift+Tab 减少缩进

- [x] `- [ ]` 创建任务列表
- [ ] 单击方框即可勾选

## 表格

输入 `|名称|角色|` 后按回车,或使用 **Ctrl+T**。鼠标移到表格上时会出现添加、移动和对齐行列的按钮。

| 工具 | 用途 |
| :-- | :-- |
| Ctrl+T | 插入表格 |
| Tab | 跳到下一个单元格 |

## 公式

行内公式:$E = mc^2$;单独成行则输入 `$$` 后按回车:

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

## 图表

语言设为 `mermaid` 的代码块会变成图表:

```mermaid
graph LR
  A[写作] --> B[保存]
  B --> C[导出为 PDF 或 Word]
```

## 代码

```js
// 支持 100 多种语言的语法高亮
function greet(name) {
  return `你好,${name}!`;
}
```

## 图片

粘贴图片 (Ctrl+V) 或拖入窗口:图片会复制到文档旁边的 `assets` 文件夹,并以相对路径插入,文档因此可以随处移动。文件夹可在首选项中更改。

## 脚注

Markdown 支持脚注[^1]:使用“段落 > 脚注”。

[^1]: 就像这一条。

## 常用快捷键

| 操作 | 按键 |
| --- | --- |
| 快速打开文档 | Ctrl+P |
| 命令面板 | Ctrl+Shift+A |
| 源代码模式 (原始 Markdown) | Ctrl+U |
| 专注模式 | F8 |
| 打字机模式 | F9 |
| 查找 / 替换 | Ctrl+F / Ctrl+H |
| 在整个文件夹中搜索 | Ctrl+Shift+F |
| 侧边栏 | Ctrl+Shift+L |
| 写作助手 (Ollama) | Ctrl+J |
| 标题 1-6、段落 | Ctrl+1 … Ctrl+6、Ctrl+0 |
| 项目符号、编号、任务列表 | Ctrl+Shift+8、7、9 |

完整列表见 **帮助 > 键盘快捷键**。

## 超越 Typora

- **标签页**:同一窗口中打开多个文档 (Ctrl+Tab 切换)。
- **版本历史**:每次保存都会保留副本;在“文件 > 版本历史”中查看差异并恢复。
- **自动恢复**:电脑突然关机后,重启即可找回未保存的文本。
- **文件夹搜索**:在一个文件夹的所有文档中查找词语。
- **[[维基链接]]**:兼容 Obsidian 库;Ctrl+单击打开笔记。
- **本地助手**:安装 [Ollama](https://ollama.com) 后,无需把文本发到网上即可校对、翻译、摘要或改写。
- **导出为 Word**:无需额外程序。
- **九种语言**:视图 > 语言。
